HOW TO GET THE APK (no Android Studio needed)
1. Create a free account at github.com and a new PRIVATE repository (e.g. suntree-desk).
2. Upload everything in this folder to it (drag and drop on the repo page; keep the .github folder).
3. Open the Actions tab -> "Build Android APK" -> Run workflow. Wait about 5-8 minutes.
4. Open the finished run -> Artifacts -> download "Suntree-Desk-APK" -> unzip -> app-debug.apk.
5. Send app-debug.apk to your phone, allow "Install unknown apps", and install.

Notes: data is stored inside the app on that phone only. Debug APK is fine for your own use; it is not for the Play Store.
